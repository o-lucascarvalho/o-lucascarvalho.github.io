# Lucas Carvalho — Portfolio

Minimal personal portfolio built with React, TypeScript and Vite.

## Local development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Customize

Edit the main profile content in:

```text
src/data/profile.ts
```

Optional assets:

```text
public/profile.jpg
public/resume.pdf
```

If `public/profile.jpg` is missing, the site displays an `LC` fallback block.

## Build

```bash
npm run build
```

## GitHub Pages

For a user site repository named:

```text
o-lucascarvalho.github.io
```

the default Vite base path `/` works correctly.
